# خطة إضافة قسم التحصيل ونسب التحصيل

## النتيجة
إضافة تبويب إداري مستقل باسم **التحصيل ونسب التحصيل** دون تغيير جداول أو صفحات أو حسابات التوريدات الحالية. يستخدم القسم نفس الفروع والمناطق والمحصلين، لكن يحتفظ بدوراته وعملياته وتقاريره في جداول منفصلة.

## قاعدة البيانات والأمان
- إنشاء `collection_cycles` لدورات التحصيل الشهرية مع الفرع والمنطقة والمحصل والربط وعدد الفواتير وتاريخ وصول الربط والحالة وبيانات الإغلاق والنتائج النهائية المثبتة.
- إنشاء `collection_entries` لكل دفعة تحصيل دورية داخل الدورة، وإنشاء `other_revenue_items` لبنود الإيرادات الأخرى المنفصلة.
- ربط الجداول بالمستخدمين والفروع والمناطق الحالية فقط، دون نسخها، مع إبقاء دورة الشهر مفتوحة حتى يغلقها المدير يدويًا.
- إضافة عرض حسابي آمن يجمع لحظيًا: متحصلات الفواتير، الإيرادات الأخرى، الإجمالي العام، ونسبة التحصيل؛ وعند غياب الربط لا تُجرى القسمة.
- إضافة إجراءات آمنة لإغلاق الدورة وإعادة فتحها، وتثبيت النتائج ووقت الإغلاق ومن أغلقها، ومنع إدخال أو تعديل عمليات دورة مغلقة.
- تطبيق صلاحيات مستوى قاعدة البيانات: المدير يدير كل الدورات والعمليات، والمحصل يمكنه قراءة دورته وعملياتها فقط، ولا توجد صلاحية له لرؤية بيانات غيره أو تعديل الدورات.
- تسجيل إنشاء الدورة، إضافة التحصيل، الإغلاق، وإعادة الفتح في سجل العمليات.
- تضمين بيانات دورات تجريبية وعمليات تحصيل لعرض المقارنات والرسوم مباشرة.

## واجهة الإدارة
- إضافة التبويب الجديد إلى القائمة الرئيسية، مع صفحة ملخص مستقلة تعرض الدورة الحالية وإجماليات الربط والتحصيل والنسبة والإيرادات الأخرى والإجمالي.
- نموذج إنشاء دورة يدعم الشهر والسنة والفرع والمنطقة والمحصل والربط وعدد الفواتير وتاريخ الوصول والملاحظات، مع ترشيح المناطق والمحصلين حسب الفرع والمنطقة.
- قائمة للدورات المفتوحة والسابقة مع الحالة والنسبة والإجماليات وإمكانية فتح صفحة التفاصيل.
- صفحة تفاصيل لكل دورة تعرض بطاقات الملخص، جدول عمليات التحصيل، ونموذج إضافة عملية يتضمن تحصيل الفواتير وبنود إيرادات أخرى متعددة وملاحظات.
- إضافة تأكيدات واضحة لإنهاء الدورة وإعادة فتحها، وتعطيل الإدخال أثناء إغلاقها.

## التحليل والمقارنة
- فلاتر حسب السنة والشهر والفرع والمنطقة والمحصل والدورة ونطاق التاريخ.
- مقارنة آخر دورة بالدورة السابقة وإظهار مقدار التحسن أو الانخفاض بسهم واتجاه واضح.
- رسوم مستقلة لنسبة التحصيل، متحصلات الفواتير، الإيرادات الأخرى، وإجمالي المتحصلات عبر الدورات.
- جدول مقارنة الدورات مع الربط والتحصيل والنسبة والإيرادات والإجمالي.

## التفاصيل التقنية
- مساران جديدان: صفحة القسم وصفحة تفاصيل الدورة، مع بيانات تعريف خاصة بكل صفحة.
- وظائف وواجهات بيانات جديدة للقسم فقط؛ لا تعتمد أي حسابات على جدول `deposits`.
- الحسابات تأتي من قاعدة البيانات، بينما تحفظ نتائج نهائية منفصلة عند الإغلاق للمراجعة التاريخية.
- الحفاظ على RTL وتجربة الهاتف والكمبيوتر ومكونات التصميم الحالية، مع حالات تحميل وفراغ وتنبيهات نجاح وفشل.
- معالجة/التحقق من خطأ `src/lib/utils.ts`؛ الملف الحالي لا يحتوي السطر المسبب والبناء الحالي ناجح، وسيُعاد فحص الأنواع والبناء بعد التنفيذ.

## التحقق
- اختبار إنشاء دورة، إضافة دفعات وبنود متعددة، تحديث الإجماليات والنسبة، الإغلاق ومنع الإدخال، إعادة الفتح، والفلاتر والمقارنات.
- التحقق من أن صفحات التوريدات وبياناتها لم تتغير، وأن المحصل لا يستطيع الوصول إلى دورة محصل آخر.
- فحص العرض على الهاتف والكمبيوتر وفحص أخطاء البناء والتشغيل.
