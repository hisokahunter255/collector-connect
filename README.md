# Collector Connect

أريد إنشاء تطبيق ويب احترافي باللغة العربية بنظام RTL لإدارة توريدات المحصلين، ويكون بسيطًا وسهل الاستخدام من الهاتف المحمول والكمبيوتر.




اسم النظام المقترح:
نظام إدارة توريدات المحصلين




يحتوي النظام على نوعين من المستخدمين:




Admin – مدير النظام

Collector – المحصل




أولاً: نظام تسجيل الدخول




إنشاء صفحة Login تحتوي على:




اسم المستخدم

كلمة المرور

زر تسجيل الدخول




بعد تسجيل الدخول يتم تحديد صلاحية المستخدم تلقائيًا.




إذا كان المستخدم Admin يتم توجيهه إلى لوحة تحكم الإدارة.




إذا كان المستخدم Collector يتم توجيهه إلى الصفحة الخاصة به فقط.




يجب منع أي محصل من الوصول إلى بيانات أي محصل آخر أو أي فرع أو منطقة غير مخصصة له.




استخدم نظام Authentication آمن وقاعدة بيانات Supabase.

الأمان والصلاحيات




هذه النقطة مهمة جدًا.




استخدم Supabase Row Level Security – RLS.




المحصل يستطيع فقط:




قراءة بيانات حسابه

إضافة توريد خاص بحسابه

مشاهدة توريداته فقط




ولا يستطيع الوصول إلى:




حسابات المحصلين الآخرين

توريدات المحصلين الآخرين

الفروع والمناطق غير المصرح له بها

لوحة الإدارة




Admin يستطيع الوصول إلى جميع البيانات.




لا تعتمد فقط على إخفاء الصفحات في الواجهة، بل طبق الصلاحيات على مستوى قاعدة البيانات أيضًا.
